# یابنده‌ی محصول پرفروش (sh-app)

ابزار پیدا کردن محصول مناسب تولید با تحلیل دیجی‌کالا، ترب و باسلام.

- **کشف پرفروش‌ها**: دسته/عبارت + مرتب‌سازی (پرفروش، پربازدید، ...) → لیست با «امتیاز فرصت».
- **تحلیل لینک**: لینک یک محصول → همه‌ی اطلاعات (قیمت، فروشندگان، مشخصات، نظرات) + محصول مشابه در سایت‌های دیگر + تاریخچه‌ی قیمت/نظرات از اجراهای قبلی.
- ذخیره‌ی محصولات و خروجی CSV.

## معماری
- `backend/` پایتون (FastAPI + SQLite). در ویندوز با PyInstaller به `backend.exe` تبدیل شده و برنامه آن را خودش اجرا می‌کند (نیازی به سرور بیرونی نیست).
- `app/` Flutter (ویندوز + اندروید/iOS). موبایل به همان کامپیوتر ویندوزی وصل می‌شود (تنظیمات ← آدرس سرور؛ در ویندوز گزینه‌ی «اتصال از شبکه‌ی محلی» را روشن کنید).

## اجرا (توسعه)
```
cd backend && pip install -r requirements.txt && python run.py   # پورت 8765
cd app && flutter create --platforms=windows,android,ios . && flutter run -d windows
```
تست‌ها: `cd backend && pytest`. ساخت نسخه‌ی ویندوز: `build_windows.bat`.

## نکات مهم
- «امتیاز فرصت» = ۶۰٪ تقاضا + ۲۵٪ رقابت کم + ۱۵٪ رضایت. هیچ سایتی آمار فروش واقعی نمی‌دهد (جز گاهی باسلام)؛ **تعداد نظرات** نماینده‌ی فروش است.
- آدرس/ساختار APIهای دیجی‌کالا، ترب و باسلام بر اساس شناخت من از آن‌هاست و **هنوز روی سایت‌های واقعی آزموده نشده** (محیط ساخت به آن‌ها دسترسی نداشت). تست‌ها با نمونه‌داده‌اند. اگر سایتی ساختارش را عوض کرد، فقط فایل همان سایت در `backend/app/scrapers/` را اصلاح کنید.
- افزودن سایت جدید (مثلاً فروشندگان چوب خام): یک کلاس جدید از `Scraper` در `scrapers/` و ثبت در `REGISTRY`.
- رعایت قوانین/شرایط استفاده‌ی سایت‌ها و نرخ درخواست معقول با خود شماست.
