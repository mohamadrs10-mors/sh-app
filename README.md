# یابنده‌ی محصول پرفروش (sh-app)

ابزار پیدا کردن محصول مناسب تولید با تحلیل دیجی‌کالا، ترب و باسلام.

- **جستجو با کلیدواژه**: «چوبی» یا «گوشی» را بنویسید؛ برنامه آن را به چند عبارت جستجو (مثل ظرف چوبی، میز چوبی، … یا قاب گوشی، شارژر، …) تبدیل می‌کند، همه را در سایت‌های انتخابی می‌گردد و نتایج را ادغام و امتیازدهی می‌کند. گروه‌ها در «مدیریت کلیدواژه‌ها» قابل ویرایش‌اند.
- **کشف پرفروش‌ها**: دسته/عبارت + مرتب‌سازی (پرفروش، پربازدید، ...) → لیست با «امتیاز فرصت».
- **تحلیل لینک**: لینک یک محصول → همه‌ی اطلاعات (قیمت، فروشندگان، مشخصات، نظرات) + محصول مشابه در سایت‌های دیگر + تاریخچه‌ی قیمت/نظرات از اجراهای قبلی.
- ذخیره‌ی محصولات و خروجی CSV.

## نصب (ساده‌ترین حالت)
یک فایل `ShApp.exe` — دابل‌کلیک کنید، تمام. (نه Python، نه Flutter، نه سرور.)

فایل را از اینجا بگیرید: GitHub ← تب **Actions** ← آخرین اجرای `build-windows-exe` ← بخش Artifacts ← `ShApp-windows` (یا از Releases اگر تگ `v1.0.0` زده شود).
اگر ویندوز هشدار SmartScreen داد: «More info ← Run anyway» (فایل امضا نشده است).

## موبایل
داخل برنامه: تنظیمات ← «اتصال موبایل از شبکه‌ی محلی» را روشن کنید، برنامه را ببندید و دوباره باز کنید. آدرسی که نشان می‌دهد (مثل `http://192.168.1.10:8765`) را در مرورگر موبایل (همان وای‌فای) باز کنید و «افزودن به صفحه‌ی اصلی» بزنید.

## معماری
- `backend/` پایتون (FastAPI + SQLite) + رابط وب فارسی (`backend/app/web/index.html`). `run.py` سرور را بالا می‌آورد و در پنجره‌ی برنامه‌ی Edge/Chrome (حالت app) باز می‌کند؛ با بستن پنجره برنامه خاموش می‌شود. اگر باز نشد، پیام خطا و فایل `%USERPROFILE%\.sh-app\log.txt` را ببینید.
- ساخت exe: `build_windows.bat` یا GitHub Actions (خودکار).
- `app/` اپ Flutter اختیاری (اگر بعدها اپ بومی موبایل خواستید)؛ برای استفاده‌ی عادی لازم نیست.

## اجرا برای توسعه
```
cd backend && pip install -r requirements.txt && python run.py
pytest
```

## نکات مهم
- «امتیاز فرصت» = ۶۰٪ تقاضا + ۲۵٪ رقابت کم + ۱۵٪ رضایت. هیچ سایتی آمار فروش واقعی نمی‌دهد (جز گاهی باسلام)؛ **تعداد نظرات** نماینده‌ی فروش است.
- آدرس/ساختار APIهای دیجی‌کالا، ترب و باسلام بر اساس شناخت من از آن‌هاست و **هنوز روی سایت‌های واقعی آزموده نشده** (محیط ساخت به آن‌ها دسترسی نداشت). تست‌ها با نمونه‌داده‌اند. اگر سایتی ساختارش را عوض کرد، فقط فایل همان سایت در `backend/app/scrapers/` را اصلاح کنید.
- افزودن سایت جدید (مثلاً فروشندگان چوب خام): یک کلاس جدید از `Scraper` در `scrapers/` و ثبت در `REGISTRY`.
- رعایت قوانین/شرایط استفاده‌ی سایت‌ها و نرخ درخواست معقول با خود شماست.
